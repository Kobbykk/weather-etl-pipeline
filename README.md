# Automated API-to-Data Warehouse Pipeline

## Overview

This project builds an end-to-end data engineering pipeline that extracts data from a public API, transforms and validates the data using Python, and loads the processed data into PostgreSQL.

The pipeline will later be containerized with Docker and orchestrated using Apache Airflow.

## Architecture

Public API → Python Extraction → Transformation & Validation → PostgreSQL → SQL Analytics

## Technologies

- SQL
- PostgreSQL
- Docker
- Apache Airflow
